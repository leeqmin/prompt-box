# 문항 프롬프트 저장소

문항을 만들 때 쓰는 프롬프트를 보관하고, 그 프롬프트로 만든 결과 문항(최대 3개, 사진 포함)과 좋았던 점·나빴던 점을 함께 기록하는 개인용 앱입니다.

**앱 주소:** https://leeqmin.github.io/prompt-box/

## 데이터는 내 기기에만 저장됩니다
- 프롬프트, 결과 문항, 사진은 **지금 쓰는 기기의 브라우저 안에만** 저장됩니다. 서버로 아무것도 보내지 않습니다.
- 같은 주소를 다른 사람이 열어도 서로의 데이터는 보이지 않습니다.
- 노트북과 폰은 자동으로 맞춰지지 않습니다. 옮기려면 아래 백업 파일을 씁니다.
- 브라우저 데이터를 지우면 함께 사라지니 **가끔 백업**해 두세요.

## 쓰는 법
- **새 프롬프트**: 제목, 과목·단원·형식, 태그, 판정(좋음/나쁨/미정), 자세함(1~5), 본문, 메모를 적습니다.
- **결과 문항**: 수정 화면에서 「결과 추가」(최대 3개). 문항 텍스트에 `$...$`, `$$...$$`로 수식을 쓰면 보기 좋게 표시됩니다.
- **사진**: 결과 칸을 누른 상태에서 캡처한 화면을 **Ctrl+V**로 붙여넣거나, 「사진 선택」 또는 끌어다 놓기로 넣습니다. 폰에서는 갤러리·카메라에서 고릅니다.
- **복사**: 상세 화면의 「복사」로 프롬프트 본문을 복사해 씁니다.
- **복제해서 새 버전으로**: 프롬프트를 고쳐 보고 싶을 때 원본은 두고 "(v2)"로 새로 만듭니다.
- **좋은/나쁜 프롬프트 탭**: 판정으로 나뉩니다. 나쁜 프롬프트도 이유와 함께 남겨 두세요.

## 백업
「⚙ 설정」에서
- **백업 파일로 저장**: `prompt-box-backup-날짜.json` 파일 하나에 사진까지 모두 들어갑니다.
- **백업 파일 불러오기**: 지금 데이터와 합칩니다. 같은 프롬프트는 더 최근에 고친 쪽이 남고, 적용 전에 개수를 보여 줍니다.
- 다른 기기로 옮기거나 다른 사람에게 내 프롬프트를 넘길 때도 이 파일을 보내면 됩니다.

## 앱처럼 설치하기
- **iPhone (Safari)**: 공유 버튼 → 「홈 화면에 추가」
- **Android (Chrome)**: 메뉴(⋮) → 「앱 설치」 또는 「홈 화면에 추가」
- **노트북 (Chrome·Edge)**: 주소창 오른쪽의 설치 아이콘 → 「설치」

설치하면 인터넷이 없어도 열립니다. 새 버전이 나오면 위쪽에 「새 버전이 있습니다 · 새로고침」이 뜹니다.

## 개발
빌드 과정 없는 정적 사이트입니다(HTML·CSS·JavaScript, IndexedDB, KaTeX 0.16.11 포함).

테스트(헤드리스 Chrome으로 `tests/browser.html` 실행):
```
pip install playwright
python tests/run.py            # 전체
python tests/run.py model,db   # 일부
```
새로 배포할 때는 `js/version.js`와 `sw.js`의 버전을 같이 올리고, 파일을 추가했다면 `sw.js`의 `ASSETS`에도 넣습니다(테스트가 확인합니다).
